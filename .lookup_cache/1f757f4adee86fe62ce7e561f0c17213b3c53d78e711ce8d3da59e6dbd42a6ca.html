使用說明

嘸蝦米查碼提供注音螢幕鍵盤、同音字、萬用字元與罕用字查詢模式。

注音螢幕鍵盤

在網頁上實作螢幕觸控輸入法，很難提供像系統原生輸入法一樣的流暢度。如果您使用過程中有漏字或觸控不靈敏的問題，不妨放慢打字速度，感謝您的理解。

同音字查詢

如果不知道「嘉」字的拆碼，但知道「加」的讀音一樣為 ㄐㄧㄚ 且拆碼為 DOO，則可以使用 ' 為前導鍵來啟用同音字查碼。在查詢欄位中輸入 'DOO 即可以從所有讀音為 ㄐㄧㄚ 的字中找到我們想要查詢的「嘉」。

  • 查詢 'DOO「加」，讀音 ㄐㄧㄚ，可以看到「加、家、嘉、佳、傢…」
  • 查詢 'UOO「台」，讀音 ㄊㄞˊ，可以看到「台、臺、抬、颱、苔…」
  • 查詢 'OVFF「嘸」，讀音 ㄨˇ，可以看到「嘸、五、午、武、舞…」

萬用字元模式

  • * 或 [ 表示一至多個不確定字根
  • ? 或 ] 表示單個不確定字根

如果只知道「嘸」字的拆法開頭是 OV，卻不知道後面怎麼拆，可以查詢 OV* 或 OV[，就可以在所有拆碼以 OV 為首的字中找到「嘸」。

  • 查詢 OV* 或 OV[，可以看到「唯 OVE、咋 OVF、噍 OVF、嘸 OVFF、咈 OVJ…」
  • 查詢 OV?? 或 OV]]，可以看到「嘸 OVFF、鷕 OVNF、囔 OVNK、嗽 OVSI、喇 OVSR…」
  • 查詢 A?B 或 A]B，可以看到「鎯 AAB、錕 ADB、鄶 ADB、錪 AFB、鏷 AFB…」

罕用字查詢

啟用罕用字查詢時，會載入 Unicode 中日韓統合表意文字擴充區（CJK Unified Ideographs Extensions）約五萬多筆罕用字，如果您的電腦或手機處理器較舊，與萬用字元模式一起使用時可能會有卡頓的情形。
